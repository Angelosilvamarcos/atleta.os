# ATLETAOS 2.0

Plataforma de treino e performance baseada na consolidação das versões anteriores do ATLETAOS.

## Stack
- React
- Vite
- JavaScript
- Persistência local nesta primeira etapa

## Rodar localmente
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
